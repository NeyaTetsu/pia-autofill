下記の要件でChrome拡張機能を作成してください

1.設定画面に下記の項目を作成、設定はローカルストレージに保存されるようにする
- 名前
  姓/名でinputを分ける
- フリガナ
  姓/名でinputを分ける
  全角カナ以外が入力された場合は"全角のカタカナで入力してください"と案内する
- 性別
  ラジオボタンで"女性""男性""その他""回答しない"の順番にする
  valueは女性:"2" 男性:"1" その他:"8" 回答しない:"9"にする
- 生年月日
  年/月/日でinputを分ける
  inputはnumber形式にする
- 電話番号
  "-"でinputを3つに分ける
  プレースホルダーは携帯電話番号
- メールアドレス
- 郵便番号
  "-"でinputを2つに分ける
- 住所（番地） ※全角26文字まで、番地がない方は「番地なし」と入力
  26文字を超えた場合はエラーメッセージを表示する
- 申込状況照会用パスワード ※半角英数字6～16桁、忘れないよう大切に保管してください
  6桁未満または16桁を超えた場合や半角英数字以外を入力した場合は"6桁以上16桁以内の半角英数字で入力してください"とエラーメッセージを表示する

2."https://va.pia.jp/*"にアクセスした際に、nameが"cstmr_lnm"と"cstmr_fnm"のinputが2つとも存在する場合、"フォームに自動入力する"と書かれたボタンを画面右上にフローティング表示

3.それぞれのnameのinputに、下記の通りに設定した内容をフォームに自動入力、存在しないinputは無視する
- "cstmr_lnm" = 名前 性
- "cstmr_fnm" = 名前 名
- "cstmr_lkn" = フリガナ 性
- "cstmr_fkn" = フリガナ 名
- "sex_typ" = 性別
- "birth_yyyy" = 生年月日 年
- "birth_mm" = 生年月日 月（1桁の場合は先頭に0を付ける）
- "birth_dd" = 生年月日 日（1桁の場合は先頭に0を付ける）
- "telno1" = 電話番号 1つ目
- "telno2" = 電話番号 2つ目
- "telno3" = 電話番号 3つ目
- "ml_addr" = メールアドレス
- "ml_addr_cnfm" = メールアドレス
- "cmnt01" = 郵便番号 1つ目
- "cmnt02" = 郵便番号 2つ目
- "cmnt14" = 住所（番地）
- "gnrl_cstmr_passwd" = 申込状況照会用パスワード
